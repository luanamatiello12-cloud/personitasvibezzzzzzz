# Ateliê de Personagens VBZ

Criador de personagens em pixel art para a VBZ (NPCs e avatares jogáveis).

Abra `index.html` no navegador ou acesse o site pelo GitHub Pages.

- Os personagens ficam salvos no navegador de quem cria.
- **Copiar lista** gera um texto com um código `VBZ1:` para enviar a outra pessoa.
- **Importar** recebe esse texto e adiciona os personagens à lista.

`atelie.html` é a fonte da página; `index.html` é a mesma página com o cabeçalho HTML completo.

## Créditos dos bonecos

Os desenhos dos bonecos vêm da base aberta **Liberated Pixel Cup (LPC)**, pelo
[Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator).
Licenças: CC-BY-SA 3.0 / GPL 3.0 (algumas peças também OGA-BY 3.0). Os artistas de cada peça
estão listados em `lpc/CREDITS.csv`. Os bonecos gerados aqui são obras derivadas e seguem as mesmas licenças.
